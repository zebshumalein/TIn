How it works

Four simple steps from your data to an answer you can trust.

  1. 1

    Upload your data

    Drop in a spreadsheet or CSV. Nothing to set up, and no coding needed.

  2. 2

    Ask in plain English

    Type your question the way you would ask a colleague. For example: 'Which region earned the most?'

  3. 3

    We calculate, not guess

    Instead of guessing a number, the AI writes a small program and runs it on your real data. Only the program does the maths.

  4. 4

    We prove it

    We run the calculation a second time on its own. If both runs match, you see a green Verified badge, along with the code and the exact rows used.

  • Honest when unsure

    It says “I can't prove this” instead of inventing an answer.

Frequently asked questions

Is my data stored?

Your file is used only to answer your questions during this session.

What file types work?

Upload up to 5 CSV or Excel files (.xlsx, .xls), up to 10 MB each and 20 MB combined.

What if the AI is wrong?

You can read the code and see the exact rows, and the second run must match or you get a warning instead of an answer.

Can I ask about things not in my data?

No. If the data cannot answer it, the app says so.
